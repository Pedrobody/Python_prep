[**Abrir el simulador**](https://silver-fortnight-4j7qq5xrvq36qx-8000.app.github.dev/)

1. Lee el enunciado de la izquierda.
2. Completa la función en el editor de la derecha.
3. Pulsa **Ejecutar ejemplo** para ver su salida o **Comprobar** para ejecutar los tests.

Tu código se guarda automáticamente en el Codespace. Cambia de etapa con los cinco botones superiores. No necesitas abrir carpetas, notebooks ni una terminal.

Puedes consultar los datasets desde **Datos de ejemplo** y descargar una copia de tu trabajo con **Descargar código**. El borrador de la interfaz se guarda en el Codespace, no se publica automáticamente en GitHub. No borres el Codespace si quieres conservarlo.

Empieza por **01 · Limpieza**, sin cronómetro. Si un test devuelve NotImplementedError, esa función todavía está pendiente.

El enlace funciona mientras el Codespace está activo. Si GitHub lo suspende, vuelve a abrir [tu Codespace](https://github.com/codespaces/silver-fortnight-4j7qq5xrvq36qx). Si la interfaz no arranca, pide en el chat que la reactive.
